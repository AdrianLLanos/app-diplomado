# Clínica San Martín — APK Release

La conexión actual utiliza las cuentas y la API del sistema web Angular.
Consulta [la configuración y compilación actualizadas](docs/INTEGRACION_API_WEB.md).
El APK actual es `Clinica-San-Martin-1.1.1.apk` (versión 1.1.1, código 3).
El nombre visible en Android y dentro de la aplicación es **Clínica San Martín**.
Ver [instalación y comprobaciones](docs/INSTALAR_APK_1_1_0.md).
La información siguiente describe una entrega anterior, incluida su lista de
limitaciones.

## Información de la entrega

- Proyecto: Gestion de Pacientes
- Versión y build: 1.0.0
- Fecha de entrega: 31/08/2026

## Requisitos

- Dispositivo Android compatible.
- Conexión a Internet para iniciar sesión y sincronizar datos con Supabase.

## Permiso utilizado

- `INTERNET`.

## Instalación

1. Descargue `DentalCare_1.0.0_build1_release.apk`.
2. Abra el archivo desde el dispositivo Android.
3. Autorice la instalación desde la fuente utilizada, si Android lo solicita.
4. Pulse **Instalar**.
5. Abra DentalCare desde el ícono instalado.

## Credenciales

Use un usuario registrado en Supabase Authentication. Este documento no incluye credenciales personales.

## Funciones principales

- Inicio de sesión con Supabase.
- Gestión de pacientes.
- Gestión de doctores y horarios.
- Registro y control de citas.

## Limitaciones conocidas

- Los roles de administrador, doctor y paciente aún no están implementados.
- Historia clínica, tratamientos, recetas, facturación y pagos están pendientes.
