DENTALCARE - APK RELEASE

INFORMACION DE LA ENTREGA

Proyecto: Gestion de Pacientes
Version y build: 1.0.0+1
Fecha de entrega: 31/08/2026

REQUISITOS

- Dispositivo Android compatible.
- Conexion a Internet para iniciar sesion y sincronizar datos con Supabase.

PERMISO UTILIZADO

- INTERNET.

INSTALACION

1. Descargue DentalCare_1.0.0_build1_release.apk.
2. Abra el archivo desde el dispositivo Android.
3. Autorice la instalacion desde la fuente utilizada, si Android lo solicita.
4. Pulse Instalar.
5. Abra DentalCare desde el icono instalado.

CREDENCIALES

Use un usuario registrado en Supabase Authentication. Este documento no incluye credenciales personales.

FUNCIONES PRINCIPALES

- Inicio de sesion con Supabase.
- Gestion de pacientes.
- Gestion de doctores y horarios.
- Registro y control de citas.

LIMITACIONES CONOCIDAS

- Los roles de administrador, doctor y paciente aun no estan implementados.
- Historia clinica, tratamientos, recetas, facturacion y pagos estan pendientes.
